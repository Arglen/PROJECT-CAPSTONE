# SignLink - Real-Time Sign Language Translation & Curriculum Hub

SignLink is an Android application built with Kotlin and Jetpack Compose that uses CameraX and Google MediaPipe Vision to perform on-device real-time 21-hand-landmark detection, sign language translation, and Text-to-Speech vocalization.

## Administrative Role Setup
To make an admin: register an account, then in the Firebase console set users/{uid}.role to ADMIN.
